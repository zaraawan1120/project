# My Personal Website

A simple static personal website, auto-deployed to GitHub Pages via GitHub Actions.

## Structure

- `index.html` — main page
- `style.css` — styling
- `script.js` — small bit of interactivity
- `.github/workflows/deploy.yml` — CI/CD pipeline that publishes this site to GitHub Pages on every push to `main`

## Live site

Once deployed: `https://<your-username>.github.io/<your-repo-name>/`
